# Police Job System

A simple police job system for FiveM servers with job selection and teleportation.

## Features

- Job selection menu for players
- Teleportation to police station upon job selection

## Requirements

- FiveM server
- ESX framework

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start policeJobSystem` to your server.cfg file.

## Usage

1. Players can open the job menu by typing `/Menu` in the chat.
2. Select the police job from the menu.
3. Players will be teleported to the police station.

## Configuration

Edit the `config.lua` file to customize the police job name, label, grade, and spawn coordinates.
